# 48. Go-live decisions

**What it is for:** Before switch-over day, the accountant and the owners must answer important questions about how the business works. This register keeps track of those questions and records what was decided.

**Before you start:** Read the question and look for the **Default:** answer. This default is the safest choice if you are not sure what to decide.

### Steps
1. On the **Accounting & Tax** menu, click **Go-live decisions**.
2. Under **Who must decide**, pick **Everyone**, **Accountant**, **Owner**, or **Co-owners** to see different questions.
3. For a question, read the current status.
4. Type the answer in **What was decided (or done)**.
5. Type **Who decided it** and pick the **Decision date**.
6. Type a **Note** if you want to explain why.
7. Click **Record new answer**.
8. Click **Print for signature** to print all questions and answers for signing.

### What the system does for you
It keeps a full history of your answers. If you answer a question again later, the old answer stays in the **History**. For some questions, the system checks how the app is set up. If the recorded answer does not match the app's rules, it warns you: **Warning: the recorded answer differs from this setting.** and provides an **Open Settings** link so you can fix the app's setup to match your decision.

### Common mistakes and how to fix them
- **Mistake:** A question has a warning that the recorded answer differs from the **Current setting:**.
- **Fix:** This means the app is not set up the way you decided. Click **Open Settings** to change the app's setting, or cancel and redo by recording a new answer in the register if the decision has changed.
