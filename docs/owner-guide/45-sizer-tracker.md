# 45. Sizer Tracker

**What it is for:** See which sizer sets are in the shop, which ones are out with customers, and check who is late to bring them back. Record when you lend a set and when a customer returns it.

**Before you start:** Know which customer is borrowing the set and when they promised to bring it back. For returns, you need to know if the set came back complete or if something was lost or damaged.

### Steps

**To record a sizer visit (lending a set):**
1. On the **Production** menu, click **Sizer sets**.
2. Find the set in the list and click **Lend**.
3. Under **Who is borrowing it?**, pick the customer.
4. Under **Due back on**, pick the date.
5. Click **Lend it**.

**To record a return:**
1. On the **Production** menu, click **Sizer sets**.
2. Find the set in the list and click **Take back**.
3. Under **What came back?**, choose if it is back in the shop or if it is lost or damaged.
4. Under **Condition**, type what is wrong, or type "Complete" if nothing is wrong.
5. Click **Record the return**.

**To follow up on the ones still waiting:**
1. On the **Production** menu, click **Sizer sets**.
2. Look for the yellow **Overdue** message at the top. It lists the sets that are late, who has them, and how late they are.
3. You can also see a red line next to the set in the list if it is overdue.

### What the system does for you
It keeps track of where every sizer set is. It automatically spots sets that are past their due date and highlights them as overdue. When a set comes back, it adds a record to the Returned list at the bottom so you can see its history and condition.

### Common mistakes and how to fix them
- **Mistake:** A customer lost the set or ruined it, and they paid for it.
- **Fix:** Record the return and choose "The set is lost or damaged". The system does not charge them here. You need to go and record a quick sale to take their money for the ruined set.
- **Mistake:** You lent the set to the wrong customer or put the wrong due date.
- **Fix:** Cancel and redo it. Take the set back, type that it was a mistake in the Condition box, and then lend it again to the right person with the correct date.
