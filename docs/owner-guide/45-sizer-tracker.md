# 45. Sizer Tracker

**What it is for:** See which sizer sets are in the shop, which ones are out with customers, and check who is late to bring them back. Record when you lend a set and when a customer returns it.

**Before you start:** Know which customer is borrowing the set and when they promised to bring it back. For returns, you need to know if the set came back complete or if something was lost or damaged.

### Steps

**To lend a set:**
1. On the **Production** menu, click **Sizer sets**.
2. Find the set in the list and click **Lend**. This button shows only for a set that is in the shop, and only if you are allowed to change sizer loans. You can search the list, or use the status drop-down to narrow it.
3. Under **Who is borrowing it?**, pick the customer.
4. Under **Due back on**, pick the date (it starts one week from today). The set goes out today.
5. Click **Lend it**.

**To record a return:**
1. On the **Production** menu, click **Sizer sets**.
2. Find the set in the list and click **Take back** (shown for a set that is lent out).
3. Under **What came back?**, choose **The set is back in the shop** or **The set is lost or damaged**.
4. Under **Condition**, type what is wrong, or type "Complete" if nothing is wrong.
5. Click **Record the return**.

**To follow up on the ones still waiting:**
1. On the **Production** menu, click **Sizer sets**.
2. Look for the **Overdue** message at the top. It lists the sets that are late, who has them, and how late they are.
3. In the list, a late set also has a red bar at the left of its row. Under **Who has it** you see when it went out, when it is due, and how late it is.

### What the system does for you
It keeps track of where every sizer set is. It spots sets that are past their due date and shows them as overdue. A set can be lent only while it is in the shop, and taken back only once. When a set comes back, it adds a line to the **Returned** list at the bottom with the dates and the condition. Nothing is posted to the books.

### Common mistakes and how to fix them
- **Mistake:** A customer lost the set or ruined it, and they paid for it.
- **Fix:** Record the return and choose **The set is lost or damaged**. The system does not charge them here. Record a quick sale to take their money for the set.
- **Mistake:** You lent the set to the wrong customer or put the wrong due date.
- **Fix:** Cancel and redo it. Take the set back (choose **The set is back in the shop**), type that it was a mistake in the **Condition** box, and then lend it again to the right person with the correct date.
