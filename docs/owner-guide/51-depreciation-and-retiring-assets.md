# 51. Depreciation run and retiring an asset

**What it is for:** Run the depreciation for a month so that the cost of your fixed assets is charged over time, or record taking a fixed asset off the books when it is thrown away or lost. If you are selling an asset instead, that is a different screen (see Guide 46).

**Before you start:** Know the month you need to run depreciation for. Runs go month by month. A run for an earlier month is dated on the last day of its month, but a run for this month is dated today. For retiring an asset, you will need to know which asset it is and why it is being taken off.

### Steps
**To run depreciation:**
1. On the **Money** menu, click **Fixed assets**. (You can also do this from an individual asset's page. The **Run depreciation** button only shows if you have permission to record runs.)
2. Click the **Run depreciation** button to open the "Run depreciation" dialog.
3. Pick the **Month to depreciate**. The system will help by showing a hint like "The latest run so far is <month>. Runs go month by month." or "No run has been recorded yet."
4. Check the summary shown on the screen and click **Record the run**.

**To retire an asset:**
1. On the **Money** menu, click **Fixed assets**.
2. Find the asset in the list and click on its number.
3. Click the **Dispose of this asset** button to open the "Take <asset> off the books" dialog.
4. Choose **Retired**.
5. Type **Why is it being taken off?**.
6. Read the summary shown on the screen and click **Record the disposal**.

### What the system does for you
For a depreciation run, it calculates the charge for each asset that is in service during that month, updates their book values, and adds the run to the asset register. For retiring an asset, because nothing is received for it, the book value left is charged as a loss.

### Common mistakes and how to fix them
- **Mistake:** You missed a month and the system shows a yellow warning: "No depreciation was recorded for... Run the months from the oldest, so each month's charge falls in its own books."
- **Fix:** Pick the oldest missed month in the **Month to depreciate** list and record it. Repeat this until you catch up to the current month. If you recorded a run by mistake, go to the asset, click the depreciation run document number, click **Cancel**, give a reason, and click **Cancel document**. This reverses the charge.
